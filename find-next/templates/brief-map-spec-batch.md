## 阻塞关系的规则

- 本组的执行票之间：`blocked_by` 写 `T<n>`。
- 必须等同批另一组完成：写那一组的规格 key（如 `S2`，表示等那份规格整体合并）。只给真正依赖它的执行票挂，能独立开工的部分不要挂。
- 仓库里已有的、还没关闭的**规格**或**有人在修的缺陷票**：写 `#票号`。
- **不要**挂在还没有规格的地图实现票上（例如另一张还在「缺规格」的 Web UI 实现票）：那样本规格要等对方的规格写完、实现完才能收尾。把依赖它的那部分工作从本规格里拿掉，写进 `spec.md` 的 Out of Scope，并在清单 `handoffs` 里给那张票留一条说明，让它写规格时纳入。
- 拿不准时按下文「未决的两种处理」处理，不要猜。

## 写作要求

- 先判断这张地图的目的地是否适合拆成多份可独立交付的规格。本次仍只产出一份规格；如果你认为应拆，把建议和边界写进 `result.md`，并把「是否拆成多份规格」写进清单 `unresolved`（带推荐答案）。
- **只综合已拍板的东西。** `spec.md` 的每条实现决定后面用括号注明出处（`（#24 结论）`、`（地图 #@@MAP@@ Notes）`、`（ADR 0015）`）。
- `spec.md` 第一行固定为 `地图：#@@MAP@@`，然后按 to-spec 模板写 `## Problem Statement` 等各节。不要写 `实现票：` 行。
- 执行票按 to-tickets 的 issue 模板写。`## Parent` 下一行写 `#{{@@KEY@@}}`，发布时会替换成规格票号；正文里提到本组别的执行票写 `#{{T<n>}}`（如 `#{{T2}}`），提到别组规格写 `#{{S<n>}}`（同批其他组的 key）。只有 `{{S<n>}}`、`{{T<n>}}`、`{{S<n>/T<n>}}`、`{{#<n>}}` 四种算占位符，其他花括号文本（例如产品自身的模板语法）原样保留。阻塞关系写进清单的 `blocked_by`，执行票正文里的 `## Blocked by` 一节照样写（用同样的占位符）。
- 执行票要用到 ssh-manager MCP、真机或远程服务器的（不能交给 codex worker 做的），在正文里写明「本票由 Opus 执行」。
- 用中文，遵守目标仓库的写作规范。

## 未决的两种处理

找不到出处的事项分两种，不要一律写进 `unresolved`：

1. **实现者按现有习惯就能定的细节**（字段名、审计动作名、错误文案措辞、排序方式这类，仓库里有同类先例可循）：不进 `unresolved`。在 `spec.md` 里写成「由实现者沿用现有 X 的习惯确定」，并点名那个先例。
2. **需要 owner 拍板的事项**（影响用户能看到的命令名或界面、安全语义、范围归属、规格拆分、阻塞关系）：写进 `unresolved`，每条必须带你的推荐答案，并写明采纳后要改草稿的哪几处，让调用方能直接照改。`spec.md` 和执行票里先按推荐答案写，在该处加「（待确认）」。

## manifest.json 格式

```json
{
  "key": "@@KEY@@",
  "map_number": @@MAP@@,
  "title": "规格标题",
  "body": "spec.md",
  "tickets": [
    {"key": "T1", "title": "执行票标题", "body": "tickets/T1.md", "blocked_by": []},
    {"key": "T2", "title": "…", "body": "tickets/T2.md", "blocked_by": ["T1", "S2", "#212"]}
  ],
  "unresolved": [
    {"question": "要 owner 拍板的问题，一句", "proposal": "推荐答案，一句", "affects": "采纳后要改的地方：spec.md 某节、T3 某条验收标准"}
  ],
  "handoffs": [
    {"issue": 84, "note": "交给那张票的说明：它写规格时要纳入什么、为什么，两三句；可以用 #{{@@KEY@@}} 指本规格"}
  ],
  "seams": "测试切入点：在哪一层测、复用哪些已有测试方式、需不需要新的切入点。两三句，给用户确认用"
}
```

`map_number` 固定为 @@MAP@@。`labels` 省略即可（默认 `ready-for-agent`）。`blocked_by` 的引用只能是本组的 `T<n>`、别组的 `S<n>`（不能是本组 @@KEY@@）、或已有的 `#票号`。没有 `unresolved` 或 `handoffs` 时写空数组。
